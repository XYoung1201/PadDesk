按键外设

勾选“独占”后，该设备原本的按键功能被屏蔽，只执行 PadDesk 的映射（Windows 版做不到）。请不要独占你正在打字用的键盘。

HOG 配置文件

HOG 目前没有 Linux 版。若把 HOG.conf 放在本机，可填写路径，让“按键序列”列出其中的热键。

投影仪 · HDMI-CEC

把手柄键或遥控键设为“投影仪 / 电视（HDMI-CEC）”即可开机、待机或切换。树莓派 5 的 HDMI0 是 /dev/cec0，HDMI1 是 /dev/cec1。服务启动时会自动注册为播放设备。

后台运行

映射由系统服务 paddesk.service 执行，开机自动启动；关闭这个窗口不影响映射。暂停 / 恢复：Ctrl+Alt+F12，或终端执行 paddesk toggle。
