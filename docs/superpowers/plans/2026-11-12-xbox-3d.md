# Xbox 3D controller implementation plan

**Goal:** Replace the schematic with an Xbox-layout 3D controller, animated input feedback and guided calibration.
**Architecture:** One native WPF `ControllerView` builds reusable mesh geometry, handles picking and animates the camera and controls. Dashboard and calibration use the same view. `ControllerLayout` translates existing confirmed mapping names; raw input remains the source of calibration truth.
**Tech stack:** Existing .NET Framework 4 / WPF / SDL. No downloaded models or additional runtime.
**Spec:** User request in this chat, including approval to proceed with Xbox standard layout.

## Constraints and review focus
- A bottom, B right, X left, Y top; offset thumbsticks; visible LB/RB and LT/RT.
- Clicking the model must never synthesize a physical input or complete calibration.
- Unconfirmed/custom names must not falsely light a known button.
- Disconnection must clear pressed states; calibration must reject a different device.
- Rendering must stop when hidden/unloaded; camera animation must be time based.
- Preserve settings and input/output behavior. Running release must be closed gracefully before replacing it.
