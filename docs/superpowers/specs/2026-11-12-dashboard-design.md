# PadDesk 主面板重构设计

## 目标与范围
以现有 WPF 3D 手柄为主视觉和按键选择入口，减少控件堆叠，统一尺寸和对齐；增加方向键像素步长编辑；统一程序、窗口和托盘图标。沿用现有 WPF / .NET Framework 和输入引擎。

## 方案选择
- A：3D 主舞台与右侧分页设置。视觉舒展，设置分组清晰，需要切换页签。用户已选择 A。
- B：3D 居中与两侧常驻面板。参数同时可见，但占用模型空间，容易拥挤。

## 具体设计（待确认）
- 顶部保留品牌、设备状态、暂停和收起入口。底部保留简短保存状态与快捷键提示。
- 主区域左侧为自适应 3D 舞台，右侧约 380–420 px 为设置面板。默认窗口约 1280 × 820，最小尺寸下保持控件可访问。
- 3D 舞台保留拖动旋转、点击聚焦、实时按压反馈和全貌入口；校准与定位操作集中在舞台工具栏，避免分散。
- 右侧分为“按键映射”和“移动设置”。点击模型按键自动切换到映射页并选择对应项；映射列表精简为实体键与输出，原始输入和对准状态放入所选项详情。详情提供输出选择、组合键录入、名称和应用操作。
- 移动设置包含左摇杆开关、速度、死区、曲线、校准入口，以及方向键水平和垂直步长输入。步长使用整数，范围沿用配置约束 1–5000 px，初值读取当前设备配置；显式应用后保存，非法输入就地提示，保留此前有效值。长按重复行为沿用已有配置。
- 常规按钮和输入框统一约 36 px 高度，文字垂直居中；页签、工具栏和表单各自保持一致间距。侧栏内容必要时滚动，3D 舞台保持可见。
- Logo 使用靛蓝底色、简化手柄轮廓与指针元素。提供多尺寸 ICO 并嵌入程序，同时设置窗口与托盘图标，避免依赖外部图标文件。

## 实现边界与验收
保留当前未提交改动和个人配置；模型点击不发送鼠标或键盘输出。编辑输入时继续暂停控制输出。设备切换时刷新参数，断开时禁止应用。

构建预览并运行现有逻辑与视觉测试；补充方向键输入校验、应用与保存相关检查，检查默认和最小窗口尺寸的渲染，确认图标资源及窗口、托盘接入。完成后构建可运行程序；不未经确认强行结束正在运行的旧实例。
